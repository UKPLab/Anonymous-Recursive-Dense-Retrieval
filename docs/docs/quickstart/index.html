Get started

Quickstart

Load the model, encode a corpus once, and search. The defaults are the paper's multi-hop configuration: the tree RDR(4, 3) read out by the global readout.
quickstart.py
from rdr import RecursiveRetriever

retriever = RecursiveRetriever("RDR-8B")      # multi-hop prompts, TreeSearch(4, 3), GlobalReadout()

corpus = {
    "d1": "The novel Harbor Lights was written by Mara Voss.",
    "d2": "Mara Voss was born in Linz, Austria, in 1961.",
    "d3": "Linz lies on the Danube, the second-longest river in Europe.",
    "d4": "Harbor Lights was adapted for the stage in 2004.",
    "d5": "Graz is the second-largest city in Austria.",
}
index = retriever.build_index(corpus)                # every document is encoded once

query = "Which river flows through the birthplace of the author of Harbor Lights?"
hits = retriever.search(query, index, top_k=3)
for hit in hits:
    print(hit["corpus_id"], round(hit["score"], 4))

search returns one list of hits per query, as sentence-transformers' semantic_search does: {"corpus_id", "score", "index"}. The root state encodes the question with the multi-hop root instruction. Each child appends one retrieved document as text, so the encoder sees the author's name before it looks for the birthplace. The global readout then ranks every candidate that any state scored, not only the documents on the selected paths.

Change the search, keep the readout

A search strategy decides which states form; the readout decides how their scores become one ranking. The readout stays the global readout unless you ask for another one. Realized outputs, such as the chains a beam retriever returns, are requested explicitly.

python
from rdr import ChainSearch, BeamSearch, BreadthSearch, ProbabilityChain

retriever.search(query, index, search=ChainSearch(depth=4))       # 4 states, still the global readout
retriever.search(query, index, search=BreadthSearch(width=8))     # RDR(2, 8): root + 8 observations
retriever.search(query, index, search=BeamSearch(width=5))        # beam search, global readout
retriever.search(query, index, search=BeamSearch(width=5),
                 readout=ProbabilityChain())                      # BeamDR's own output, requested explicitly

Single-hop retrieval

For single-hop suites the tree carries the recovery instruction: each child treats the observed document as a distractor or partial match and looks again. The root uses the benchmark's own instruction, per query if needed.

python
from rdr import RecursiveRetriever, instructions

retriever = RecursiveRetriever("RDR-8B", prompts="single-hop")   # recovery at every context level
hits = retriever.search(
    queries, index, top_k=10,
    instruction=instructions.root_for("nanobeir", "NanoSciFact"),      # the benchmark's root instruction
)

Search once, read out many times

python
from rdr import GlobalReadout, PathProduct, RRF

traversals = retriever.traverse(queries, index)        # search once: all states and their candidates
for readout in [GlobalReadout(), PathProduct(), RRF()]:
    rankings = retriever.read(traversals, index, readout)  # no encoding, same states for every readout

Two GPUs

python
retriever = RecursiveRetriever(
    "RDR-8B",
    encode_device="cuda:0",   # the encoder
    index_device="cuda:1",    # the fp16 index and the exact search
)

While one query batch is encoded on the first GPU, another is searched on the second (inflight=2, the default). See Devices & batching.
