Get started

Installation

Install from the repository. rdr builds on sentence-transformers and PyTorch, and runs on GPUs or CPU.
shell
# in the repository downloaded from https://anonymous.4open.science/r/Recursive-Dense-Retrieval
pip install .

# with the benchmark loaders used in reproduce/ (datasets, pyyaml)
pip install ".[eval]"

# editable, with the test tools
pip install -e ".[eval,dev]"
python
import rdr
print(rdr.__version__)

Requirements

  • Python ≥ 3.9, PyTorch ≥ 2.1, sentence-transformers 3.x–5.x, transformers ≥ 4.51.
  • The model. RDR-8B (weights not included in the anonymized repository) is fine-tuned from Qwen3-Embedding-8B and loads as a sentence-transformers model (last-token pooling, normalized, 4096 dimensions). Its bf16 weights need about 16 GB of GPU memory.
  • The index. Documents are encoded once. The exact search keeps the vectors in fp16 on the index device: 1M documents take 8.2 GB. A second GPU for the index keeps the encoder's GPU free (Devices & batching).
  • CPU. Everything runs on CPU in fp32, which is practical for small models and tests, and slow for an 8B encoder.

What RDR does not need

No LLM, reader or reranker: every search state is one encoder call plus one lookup in the fixed index. The index is never re-encoded during search, so it can be built offline and reused.
