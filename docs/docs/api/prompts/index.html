rdr.PromptConfig

"custom"guide[source]
classrdr.PromptConfig(root='Retrieve the first document needed to begin answering this multi-hop question.', instructions=<factory>, primary_role='continuation', wrap='replace', wrap_by_role=<factory>, head='Instruct: {instruction}\nQuery:{query}', layouts=<factory>, default_layout=<factory>, feedback_layout=None, incorrect='Retrieved (incorrect):\n{text}', strip=False, observation_max_tokens=512, name='custom')

Instructions and text layout of all states.

Parameters

  • rootstr | Nonedefault 'Retrieve the first document needed to begin answering this multi-hop question.'

    Default root instruction; a per-query instruction passed to search(..., instruction=...) overrides it (benchmark instructions differ per task).

  • instructionsDict[str, str]default <factory>

    Role -> update instruction. Roles: continuation, recovery (primary roles), recovery_view (the recovery re-encoding of a continuation tree), feedback (joint pseudo-relevance feedback), assembly (set-conditioned selection).

  • primary_rolestrdefault 'continuation'

    Role of the context-bearing states that drive the search.

  • wrapstrdefault 'replace'

    "replace": the update instruction replaces the root instruction in the head (multi-hop); "keep": the head keeps the root instruction and the update follows the query (single-hop).

Advanced parameters (9)
  • wrap_by_roleDict[str, str]default <factory>

    Per-role override of wrap.

  • headstrdefault 'Instruct: {instruction}\nQuery:{query}'

    Instruction/query line, {instruction} and {query}.

  • layoutsDict[int, ContextLayout]default <factory>

    Observation layout per number of observed documents (1, 2 …).

  • default_layoutContextLayoutdefault <factory>

    Layout for every other number of observed documents.

  • feedback_layoutContextLayout | Nonedefault None

    Layout of the joint-feedback state.

  • incorrectstrdefault 'Retrieved (incorrect):\n{text}'

    Rendering of the last observation in the multi-hop recovery view ({text}).

  • stripbooldefault False

    Strip whitespace from instruction, query and documents (single-hop protocol).

  • observation_max_tokensint | Nonedefault 512

    Token cap per injected document (multi-hop: 512); None disables it.

  • namestrdefault 'custom'

    Name of the configuration (presets set it).
