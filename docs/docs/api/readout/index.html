Global

The default. Every retained candidate is scored by all states.

rdr.GlobalReadout

"global"guide[source]
classrdr.GlobalReadout(temperature=0.05, top_k=200, level_balanced=True, include_root=True, levels=None, normalization='softmax', restrict_to_selected=False, backfill_root=False, output_top_k=200, view='primary')

Level-balanced aggregation of sparse per-state score distributions (RDR's default readout).

Parameters

  • temperaturefloatdefault 0.05

    Softmax temperature tau over raw cosine scores (paper: 0.05).

  • top_kintdefault 200

    Candidates retained per state, |C_s| (paper: 200).

  • level_balancedbooldefault True

    Average states within each level, then average non-empty levels (paper). If False every state gets equal weight (flat CombSUM).

  • include_rootbooldefault True

    Set False for the "without root" ablation (levels >= 2 only).

Advanced parameters (6)
  • levelsIterable[int] | Nonedefault None

    Only aggregate these levels (prefix readouts such as RDR(3,3) of an RDR(4,3) run).

  • normalizationstrdefault 'softmax'

    Per-state score map: "softmax" (paper), "raw", "minmax", "minmax_full".

  • restrict_to_selectedbooldefault False

    Readout B: keep only documents the search selected (E), same scores.

  • backfill_rootbooldefault False

    After restrict_to_selected, append the root ranking (single-hop protocol).

  • output_top_kint | Nonedefault 200

    Final sparse cut of the aggregated scores (paper: 200; None keeps everything).

  • viewstrdefault 'primary'

    Which view of the traversal to read ("primary" or e.g. "recovery").

Realized paths

Rank only the documents the search selected, each by its own path. Request them explicitly.

rdr.PathProduct

realized · request explicitly"path_product"guide[source]
classrdr.PathProduct(backfill_root=False)

score(d) = max over selections of d of prod_i l_i — the product of the selecting scores along the path (raw cosines, or min–max scores for TreeSearch(path_score="minmax")).

Raw cosines are below one, so a path product can only shrink along a path: the root's picks lead the list.

Parameters

  • backfill_rootbooldefault False

    Complete the list with the root ranking (documents not yet listed, in root order), as the single-hop protocol does before nDCG@10.

rdr.ChainOrder

realized · request explicitly"chain_order"guide[source]
classrdr.ChainOrder(score='logprob', backfill_root=False)

Complete chains in hop order, as returned by beam retrievers.

The complete paths (the selections of the deepest states) are sorted by score and emitted one after another, each in hop order, duplicates skipped:

  • "logprob" — sum of the states' log sparse-softmax probabilities (BeamDR's probability chain),
  • "sum" — sum of raw cosines (MDR's sequence score),
  • "product" — product of raw cosines.

Ties break by the path.

Parameters

  • scorestrdefault 'logprob'

    Path score that orders the complete chains: "logprob", "sum" or "product".

  • backfill_rootbooldefault False

    Complete the list with the root ranking (documents not yet listed, in root order), as the single-hop protocol does before nDCG@10.

classrdr.RRF(k=60, level_balanced=False, top_k=200, output_top_k=200, view='primary')

Reciprocal rank fusion of the states' ranked lists, 1/(k + rank) with ranks from 1.

Views

Fuse readouts of several views of one traversal.

rdr.ZAgreement

"z_agreement"guide[source]
classrdr.ZAgreement(*readouts, weights=None, group_reduce=None, view_top_k=200, output_top_k=None)

Fuse the readouts of two (or more) views of the same traversal by z-agreement (Eq. 5–9).

Each view is cut to its top view_top_k entries and, on chunked corpora, pooled per document (group_reduce per view: "max" or "last") before standardization, as in the paper.

Example — Table 1, "+ recovery (z-agreement)":

ZAgreement(GlobalReadout(), recovery_view_readout())

Parameters

  • *readoutsReadoutrequired

    Two or more readouts, usually of different views (e.g. GlobalReadout() and recovery_view_readout()).

  • weightsSequence[float] | Nonedefault None

    Weight of each view's z-scores (default: equal weights, as in the paper).

Advanced parameters (3)
  • group_reduceSequence[str] | Nonedefault None

    Chunk-to-document pooling per view on chunked corpora, "max" or "last" (default: "max" for every view).

  • view_top_kint | Nonedefault 200

    Entries of each view that are standardized (paper: 200).

  • output_top_kint | Nonedefault None

    Length of the fused ranking (None keeps the union of supports).
