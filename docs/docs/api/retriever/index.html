rdr.RecursiveRetriever

classrdr.RecursiveRetriever(model, prompts='multi-hop', search=None, readout=None, candidate_k=200, query_max_length=4096, document_max_length=512, batch_size=8, query_batch_size=32, encode_device=None, index_device=None, inflight=2, torch_dtype='bfloat16', encode_grouping='level')

Recursive dense retrieval with one instruction-conditioned encoder.

Parameters

  • modelrequired

    A SentenceTransformer, a model name/path, or an Encoder.

  • promptsstr | PromptConfigdefault 'multi-hop'

    A PromptConfig or a preset name ("multi-hop", "single-hop", "single-hop-continuation", "bright-pro").

  • searchstr | SearchStrategy | Nonedefault None

    Default search strategy (TreeSearch(4, 3)) or a name ("tree", "beam" …).

  • readoutstr | Readout | Nonedefault None

    Default readout (GlobalReadout()) or a name.

Advanced parameters (10)
  • candidate_kintdefault 200

    Candidates kept per state (paper: 200).

  • query_max_lengthintdefault 4096

    Token budget of a rendered state (paper and training: 4096).

  • document_max_lengthintdefault 512

    Token budget of an indexed document (paper: 512 for the multi-hop passages; the single-hop corpora were encoded with up to 8192 tokens).

  • batch_sizeintdefault 8

    Encoder batch size.

  • query_batch_sizeintdefault 32

    Queries processed together (level-synchronous batching).

  • encode_devicestr | Sequence[str] | Nonedefault None

    Device of the encoder (or a list for data-parallel encoding).

  • index_devicestr | Nonedefault None

    Device of the document index and the exact search (e.g. a second GPU).

  • inflightintdefault 2

    Query batches in flight; with separate encode/index devices, inflight >= 2 overlaps encoding of one batch with the search of another.

  • torch_dtypestr | torch.dtype | Nonedefault 'bfloat16'

    Weight dtype when model is a name or path (RDR-8B: "bfloat16").

  • encode_groupingstrdefault 'level'

    "level" (fastest), "query" or "slot" (the paper's batch composition, see rdr.search.engine.SearchEngine).

RecursiveRetriever.search(queries, index, top_k=10, search=None, readout=None, instruction=None, exclude=None, return_traversals=False, show_progress_bar=False)

Search and read out. Returns semantic_search-style hits: one list of {"corpus_id", "score", "index"} dicts per query (and the traversals if requested).

Parameters

  • queriesstr | Sequence[str]required

    One query or a list of queries.

  • indexDenseIndexrequired

    The document index (build_index).

  • top_kintdefault 10

    Hits returned per query.

  • searchstr | SearchStrategy | Nonedefault None

    Search strategy for this call, an instance or a name (default: the retriever's).

  • readoutstr | Readout | Nonedefault None

    Readout for this call, an instance or a name (default: the retriever's GlobalReadout). Views it needs (e.g. the recovery view) are encoded automatically.

Advanced parameters (4)
  • instructionstr | Sequence[str | None] | Nonedefault None

    Root instruction, one for all queries or one per query.

  • excludeOptional[Sequence[Sequence[int] | None]]default None

    Per query, index positions that may never be retrieved.

  • return_traversalsbooldefault False

    Also return the traversals, to read them out again with read.

  • show_progress_barbooldefault False

    Show a progress bar over query batches.

RecursiveRetriever.traverse(queries, index, search=None, instruction=None, exclude=None, views=(), keep_text=False, keep_embeddings=False, show_progress_bar=False)

→ List[Traversal]

Run the search and return the traversals (all states with their candidates).

A traversal can be read out any number of times with read, so readouts are compared on identical states (as in the paper's Appendix F).

Parameters

  • queriesSequence[str]required

    Query texts.

  • indexDenseIndexrequired

    The document index.

  • searchstr | SearchStrategy | Nonedefault None

    Search strategy for this call (default: the retriever's search).

Advanced parameters (6)
  • instructionstr | Sequence[str | None] | Nonedefault None

    Root instruction, one for all queries or one per query (benchmark instructions); None uses the prompt configuration's root.

  • excludeOptional[Sequence[Sequence[int] | None]]default None

    Per query, index positions that may never be retrieved (e.g. BRIGHT's excluded ids); see DenseIndex.positions.

  • viewsSequence[str | ViewSpec]default ()

    Extra views to encode over the same traversal, e.g. ["recovery"]; readouts that need a view request it automatically in search.

  • keep_textbooldefault False

    Keep each state's rendered text in the traversal.

  • keep_embeddingsbooldefault False

    Keep each state's query vector (needed by RootInterpolation).

  • show_progress_barbooldefault False

    Show a progress bar over query batches.

RecursiveRetriever.build_index(corpus, ids=None, groups=None, cache_dir=None, show_progress_bar=True)

→ DenseIndex

Encode a corpus (list of texts or {id: text}) into a DenseIndex on index_device.

Parameters

  • corpusUnion[Sequence[str], Dict[Any, str]]required

    Document texts, or a {corpus_id: text} mapping.

  • idsSequence[Any] | Nonedefault None

    Corpus ids returned in the hits (default: the mapping's keys, or 0 … N-1).

Advanced parameters (3)
  • groupsSequence[Any] | Nonedefault None

    Optional document key per entry for chunked corpora; readouts then max-pool chunk scores per document (the paper's multi-hop output processing).

  • cache_dirstr | Nonedefault None

    Directory for the document embeddings. If it already holds embeddings they are loaded instead of encoding again; the cache is not validated against the texts or the model, so use one directory per corpus and model.

  • show_progress_barbooldefault True

    Show a progress bar while encoding.

Query/document encoder built on a SentenceTransformer.

Parameters

  • modelrequired

    A SentenceTransformer (or a model name/path, loaded with load_sentence_transformer).

  • query_max_lengthintdefault 4096

    Token budget of a rendered query state (instruction + query + observations).

  • document_max_lengthintdefault 512

    Token budget of an indexed document.

  • batch_sizeintdefault 8

    Batch size for rendered query states.

Advanced parameters (5)
  • document_batch_sizeint | Nonedefault None

    Batch size for documents (default: max(batch_size, 32)).

  • document_promptstr | Nonedefault None

    Optional prompt prepended to documents (None = raw documents, RDR-8B's contract).

  • devicesSequence[Device] | Nonedefault None

    Optional list of devices for data-parallel encoding (one replica per device).

  • torch_dtypestr | torch.dtype | Nonedefault 'bfloat16'

    Weight dtype when model is a name or path (RDR-8B: "bfloat16").

  • sort_by_lengthbooldefault True

    Let sentence-transformers sort texts by length for faster batching (default). Set False to encode in the given order with fixed consecutive batches, the batch composition of the paper's runs (bf16 embeddings depend slightly on which texts share a batch).

rdr.load_sentence_transformer

[source]
rdr.load_sentence_transformer(model_name_or_path, device=None, torch_dtype='bfloat16', max_seq_length=4096, pooling='lasttoken', trust_remote_code=False)

Load a SentenceTransformer.

Hub models and local folders with a sentence-transformers config (modules.json) load directly. A plain Hugging Face checkpoint (e.g. a training checkpoint of Qwen3-Embedding) is wrapped as Transformer -> Pooling(lasttoken) -> Normalize with left padding, which is the Qwen3-Embedding contract RDR-8B was trained with.

Parameters

  • model_name_or_pathstrrequired

    Hub name ("RDR-8B") or local path.

  • deviceDevice | Nonedefault None

    Device to load the model on (default: CUDA if available, else CPU).

  • torch_dtypestr | torch.dtype | Nonedefault 'bfloat16'

    Weight dtype (RDR-8B: "bfloat16").

Advanced parameters (3)
  • max_seq_lengthintdefault 4096

    Token limit of the model's inputs.

  • poolingstrdefault 'lasttoken'

    Pooling of a wrapped plain checkpoint ("lasttoken" for Qwen3-based models).

  • trust_remote_codebooldefault False

    Passed to sentence-transformers / transformers.
