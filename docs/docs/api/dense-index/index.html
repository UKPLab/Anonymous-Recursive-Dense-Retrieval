classrdr.DenseIndex(embeddings, texts=None, ids=None, groups=None, device=None, dtype=None, normalized=False, query_chunk_size=None)

Exact inner-product (= cosine) search over normalized document embeddings.

Parameters

  • embeddingstorch.Tensor | np.ndarrayrequired

    [N, d] document embeddings. They are L2-normalized on load unless normalized=True says they already are.

  • textsSequence[str] | Nonedefault None

    Document texts, needed to render observed documents into later query states.

  • idsSequence[Any] | Nonedefault None

    External document ids returned to the user (default: range(N)).

  • devicestr | torch.device | Nonedefault None

    Where the vectors live and the search runs ("cuda:1", "cpu" …).

Advanced parameters (4)
  • groupsSequence[Any] | Nonedefault None

    Optional document key per entry for chunked corpora. Readouts can max-pool chunk scores per group (the paper's multi-hop output processing).

  • dtypetorch.dtype | Nonedefault None

    Storage/compute dtype. float16 on GPU (as in the paper), float32 on CPU.

  • normalizedbooldefault False

    The embeddings are already L2-normalized; keep their bits as given.

  • query_chunk_sizeint | Nonedefault None

    Queries scored per matmul (default: sized to a ~512 MB score block).

DenseIndex.search(queries, k, exclude=None, tie_slack=16, return_range=False)

→ SearchOutput

Top-k search for a batch of query vectors.

Parameters

  • queriestorch.Tensor | np.ndarrayrequired

    [m, d] normalized query vectors (any device/dtype).

  • kintrequired

    Number of candidates per query.

Advanced parameters (3)
  • excludeExclusiondefault None

    Optional per-row index positions that are not eligible (benchmark exclusions). They are removed before the top-K cut, i.e. before any per-state softmax.

  • tie_slackintdefault 16

    Extra candidates fetched so that ties at the cut are ordered by index.

  • return_rangebooldefault False

    Also return each row's full-column minimum and maximum score (before exclusions), used by min–max normalizations.
