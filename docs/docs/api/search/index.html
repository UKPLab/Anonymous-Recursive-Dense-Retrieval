rdr.TreeSearch

"tree"guide[source]
classrdr.TreeSearch(depth=4, branching=3, root_branching=None, dedup='level', beam=None, path_score='raw')

RDR(H, b): from the root, every state selects up to b candidates; each selection becomes a child that appends the document to its parent's observations.

Parameters

  • depthintdefault 4

    H, encoded levels including the root (paper: 4).

  • branchingintdefault 3

    b, selections per state (paper: 3).

Advanced parameters (4)
  • root_branchingint | Nonedefault None

    Selections of the root (defaults to branching).

  • dedupstrdefault 'level'

    "level" (merge per level, exclude earlier levels; multi-hop), "none" (single-hop) or "sequential" (legacy). See rdr.search.base.

  • beamint | Nonedefault None

    Keep only the beam best children per level by cumulative path score (beam search).

  • path_scorestrdefault 'raw'

    "raw" (product of raw cosines; paper) or "minmax" (product of full-column min–max normalized scores, the legacy GRITHopper/HippoRAG tree). Only affects path scores.

rdr.ChainSearch

"chain"guide[source]
classrdr.ChainSearch(depth=4, dedup='level')

A single chain of H states: TreeSearch(H, branching=1).

Parameters

  • depthintdefault 4

    H, encoded states of the chain including the root (paper: 4).

Advanced parameters (1)
  • dedupstrdefault 'level'

    Selection rule, as in TreeSearch; with one state per level "level" and "sequential" coincide (the chain never revisits a selected document).

rdr.BreadthSearch

"breadth"guide[source]
classrdr.BreadthSearch(width=8, dedup='level')

Shallow breadth RDR(2, m): the root and m independently observed candidates (Eq. 4), 1 + m encodings in two dependent rounds.

Parameters

  • widthintdefault 8

    m, the root's top-m candidates; each is observed by one level-2 state.

Advanced parameters (1)
  • dedupstrdefault 'level'

    Selection rule, as in TreeSearch (only the root selects, so the modes coincide).

rdr.BeamSearch

"beam"guide[source]
classrdr.BeamSearch(width=5, depth=4, proposals=None)

Beam search over observation paths, as in MDR / BeamDR (Appendix H.1).

The root selects W candidates. At every level each path proposes its W best candidates not selected before; proposals of one document keep the path with the highest product of raw cosines, and the W best paths survive. Every proposed document counts as selected. A width-W beam has at most 1 + (H-1) W states (W = 13 matches the 40-state ceiling of RDR(4, 3)).

The default readout stays GlobalReadout; the beam retrievers' own outputs are ProbabilityChain (BeamDR) and SequenceSum (MDR).

Parameters

  • widthintdefault 5

    W, surviving paths per level; also the root's selections.

  • depthintdefault 4

    H, encoded levels including the root.

Advanced parameters (1)
  • proposalsint | Nonedefault None

    Candidates each path proposes per level (defaults to width).

rdr.DocAsQuerySearch

"doc_as_query"guide[source]
classrdr.DocAsQuerySearch(depth=4, branching=3, root_branching=None, dedup='level', beam=None, path_score='raw')

Document-as-query expansion (COR-style, without COR's LLM aspect queries): same geometry, eligibility and deduplication as TreeSearch, but each child searches with the selected document's own index vector instead of an encoded state (Table 32).

Read it out with PostOrderRRF for COR's own aggregation, or with the default global readout.

Parameters

  • depthintdefault 4

    H, levels including the root (the root is still an encoded query).

  • branchingintdefault 3

    b, documents each state promotes to queries.

Advanced parameters (4)
  • root_branchingint | Nonedefault None

    Selections of the root (defaults to branching).

  • dedupstrdefault 'level'

    Selection rule, as in TreeSearch.

  • beamint | Nonedefault None

    Optional beam width, as in TreeSearch.

  • path_scorestrdefault 'raw'

    "raw" or "minmax" path scores, as in TreeSearch.

rdr.JointFeedback

"joint_feedback"guide[source]
classrdr.JointFeedback(m=3)

Pseudo-relevance feedback as in ANCE-PRF: the query and the root's top-m documents are encoded jointly into one second query vector, read out alone (StateReadout(level=2)).

Parameters

  • mintdefault 3

    Feedback documents, the root's top-m, observed together by the second state (paper: 3).

rdr.make_search

[source]
rdr.make_search(spec)

A search strategy from a name or a dict, e.g. make_search({"name": "beam", "width": 13}).

Parameters

  • specstr | dict | SearchStrategy | Nonerequired

    A name from SEARCHES, a dict with name plus constructor arguments, or an instance (returned unchanged).

Names

Wherever a search is expected, a name or a dict with a name and constructor arguments works too, e.g. search={"name": "beam", "width": 13}.
