Recovery fusion

Because the instruction is part of the state, the same observations encoded under another role give another view. The recovery view re-encodes every proposal of a continuation tree. It marks the path's last document as Retrieved (incorrect): and uses the chain-recovery instruction. It never changes which states were expanded. Its readout is fused with the primary readout by z-agreement.
from rdr import recovery_fusion

# the recovery view is encoded automatically
hits = retriever.search(queries, index,
                        readout=recovery_fusion())

z-agreement

Each view v is standardized on its own scored support, z_v(d) = (r_v(d) − μ_v) / σ_v, using the sample standard deviation (σ = 0 counts as 1). A document missing from a view receives that view's minimum z. The fused score is the sum, s(d) = ẑ_primary(d) + ẑ_recovery(d) (Eq. 5–9). Each view is cut to its top 200 before standardization.

How the recovery view is read

  • One recovery state per proposal of the tree, rendered with the proposal's path and the chain-recovery instruction.
  • Per state, the raw cosines are min–max normalized over the whole index column, then turned into a sparse softmax over the top-200 (τ = 0.05).
  • The states' distributions are summed, without the root and without level balancing (recovery_view_readout()).

Recall@5 (Tables 1, 20). The fusion improves Recall@5 by 1.31, less than 0.01, 2.88 and 0.49 points; the mean gain is 1.17.

Recovery fusion is an optional extension. It costs one extra encoding per proposal and is reported separately from the primary tree. On single-hop suites the recovery instruction drives the primary tree itself (Instructions).

rdr.ZAgreement

"z_agreement"guide[source]
classrdr.ZAgreement(*readouts, weights=None, group_reduce=None, view_top_k=200, output_top_k=None)

Fuse the readouts of two (or more) views of the same traversal by z-agreement (Eq. 5–9).

Each view is cut to its top view_top_k entries and, on chunked corpora, pooled per document (group_reduce per view: "max" or "last") before standardization, as in the paper.

Example — Table 1, "+ recovery (z-agreement)":

ZAgreement(GlobalReadout(), recovery_view_readout())

Parameters

  • *readoutsReadoutrequired

    Two or more readouts, usually of different views (e.g. GlobalReadout() and recovery_view_readout()).

  • weightsSequence[float] | Nonedefault None

    Weight of each view's z-scores (default: equal weights, as in the paper).

Advanced parameters (3)
  • group_reduceSequence[str] | Nonedefault None

    Chunk-to-document pooling per view on chunked corpora, "max" or "last" (default: "max" for every view).

  • view_top_kint | Nonedefault 200

    Entries of each view that are standardized (paper: 200).

  • output_top_kint | Nonedefault None

    Length of the fused ranking (None keeps the union of supports).
