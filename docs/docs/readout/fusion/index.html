Fusion rules

Fusion rules read the same per-state candidate lists as the global readout (top-K, raw cosine); only the aggregation differs. They are the ablations of the readout, and post-order RRF is COR's own aggregation.
Fusion rules
from rdr import RRF, Borda, CombMNZ
from rdr import MaxOverStates, PostOrderRRF

traversals = retriever.traverse(queries, index)
readouts = [
    RRF(k=60),
    RRF(k=60, level_balanced=True),
    PostOrderRRF(k=60),              # as in COR
    Borda(),
    CombMNZ(),
    MaxOverStates(),
]
for r in readouts:
    rankings = retriever.read(traversals, index, r)

r(d) = (1/L) Σh (1/|Fh|) Σs∈Fh ps(d) · r(D) = ⅓(0.029 + 0.564 + 0.031) = 0.208

  • RRF(k=60): Σ_s 1/(k + rank_s(d)), ranks from 1; level_balanced=True weights states like the global readout.
  • PostOrderRRF(k=60): every node's list is fused with its children's fused lists by RRF, from the leaves up to the root (COR).
  • Borda(): K − rank + 1 points per state.
  • CombMNZ(): the level-balanced (or flat) sum of sparse-softmax scores times the number of states that retain the document.
  • MaxOverStates(): the best sparse-softmax score any state gives the document.

Table 21, mean over MuSiQue, BrowseComp+, FanOutQA and FRAMES (the paper reports means only for these rows).

Rank fusion treats a confident top candidate and a near-tie alike: at k = 60, rank 1 and rank 10 of a state count 1/61 and 1/70, however far apart their scores are. The global readout keeps each state's score magnitudes through the sparse softmax.

CombMNZ and max over states are provided for completeness; the paper does not report them.

rdr.RRF

"rrf"guide[source]
classrdr.RRF(k=60, level_balanced=False, top_k=200, output_top_k=200, view='primary')

Reciprocal rank fusion of the states' ranked lists, 1/(k + rank) with ranks from 1.

Parameters

  • kintdefault 60

    RRF constant (60, as in Cormack et al.).

  • level_balancedbooldefault False

    Weight each state by 1 / (L |F_h|) as the global readout does; False sums all states with weight one.

Advanced parameters (3)
  • top_kintdefault 200

    Ranks of each state that are fused.

  • output_top_kint | Nonedefault 200

    Length of the fused ranking (None keeps every candidate).

  • viewstrdefault 'primary'

    Which view of the traversal to read ("primary" or e.g. "recovery").

rdr.PostOrderRRF

"rrf_postorder"guide[source]
classrdr.PostOrderRRF(k=60, top_k=200, output_top_k=200)

COR-style post-order aggregation: each node's list is RRF-fused with its children's fused lists (recursively, leaves first) and the root's fused list is the output.

Parameters

  • kintdefault 60

    RRF constant; COR's 1/(60 + r + 1) with ranks r from 0 equals k=60 with ranks from 1.

Advanced parameters (2)
  • top_kintdefault 200

    Ranks of each node's own list that enter the fusion.

  • output_top_kint | Nonedefault 200

    Length of the fused ranking (None keeps every candidate).

rdr.CombMNZ

"combmnz"guide[source]
classrdr.CombMNZ(level_balanced=True, temperature=0.05, top_k=200, normalization='softmax', output_top_k=200, view='primary')

(sum of normalized scores) x (number of states whose top-K contains the document).

level_balanced=True multiplies the global readout by the count (the paper's overlap-sensitive ablation); False multiplies the flat sum.

Parameters

  • level_balancedbooldefault True

    Base score is the level-balanced global readout (True) or the flat mean.

Advanced parameters (5)

    Softmax temperature of the per-state distributions.

  • top_kintdefault 200

    Candidates retained per state; also defines the count.

  • normalizationstrdefault 'softmax'

    Per-state score map, as in GlobalReadout.

  • output_top_kint | Nonedefault 200

    Length of the fused ranking (None keeps every candidate).

  • viewstrdefault 'primary'

    Which view of the traversal to read ("primary" or e.g. "recovery").
