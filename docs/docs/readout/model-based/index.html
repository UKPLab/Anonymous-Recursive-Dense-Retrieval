Readouts

Interpolation & Assembly

Two readouts use the encoder or the index again. Root interpolation searches once more with a mixed query vector. Assembly encodes the growing selected set ten times to pick complementary evidence from a candidate pool.

Root interpolation (DC-PRF)

A refinement chain read out by its last state loses the root. DC-PRF interpolates the two vectors and searches again: normalize(λ·z_root + (1 − λ)·z_last), with λ = 0.8. Cosine is linear in the query vector, so this ranks by λ·ℓ_root(d) + (1 − λ)·ℓ_last(d) over the whole index. The intermediate states still play no part.

RootInterpolation
from rdr import ChainSearch, RootInterpolation

# as in DC-PRF: one extra lookup
hits = retriever.search(
    queries, index,
    search=ChainSearch(depth=4),
    readout=RootInterpolation(lam=0.8),
)

Assembly (set-conditioned selection)

Tree states see their ancestor path, not sibling branches, so different paths can retrieve redundant evidence. Assembly adds a horizontal step that uses the same encoder. Starting from S₀ = ∅, it encodes [ι; q; ctx(S_j)] and adds the pool document with the highest cosine that is not yet in S. This repeats ten times (Eq. 10). The pool is the base readout's top-50: ten pool-restricted encoder calls, not full-index searches.

Assembly
from rdr import Assembly, RootReadout

# tree pool (Table 1, + Assembly)
hits = retriever.search(
    queries, index,
    readout=Assembly(pool=50, n=10),
)
# root pool: no tree needed
hits = retriever.search(
    queries, index,
    readout=Assembly(base=RootReadout(), pool=50),
)

Assembly returns exactly n documents from the pool first, then the rest of the base ranking. It is an optional extension, reported separately from the primary tree.
