Readouts

Global readout

The readout that makes RDR one operator for every search. Each state turns its top-K raw cosine scores into a sparse distribution. States are averaged within their level, and the levels are averaged with equal weight. A document ranks high when many states across levels retain and score it highly, including documents that no path selected.

Eq. 2 · GlobalReadout()

p_s(d) = 1[d ∈ C_s] · exp(ℓ_s(d)/τ)

/ Σ_(u∈C_s) exp(ℓ_s(u)/τ)

r(d) = (1/L) · Σ_h (1/|F_h|)

· Σ_(s∈F_h) p_s(d)

  • ℓ_s(d): raw cosine of state s and document d
  • C_s: the state's top-K candidates, K = 200 (top_k)
  • τ = 0.05 (temperature)
  • F_h: the states of level h; L: the non-empty levels (level_balanced)
  • the aggregated scores are cut to their top-200 again (output_top_k)

No encoding and no lookups: the readout only reads the saved states.

from rdr import GlobalReadout

# the default readout of every search
hits = retriever.search(queries, index)
hits = retriever.search(
    queries, index,
    readout=GlobalReadout(temperature=0.05,
                          top_k=200),
)

What the readout adds

On one saved RDR(4, 3) traversal, the paper separates the readout from the search (Tables 19–21, Recall@5, mean over four suites):

Scoring the selected documents with all states instead of their own path (A → B) raises mean Recall@5 by 2.5 points. Adding the unselected candidates (B → C) leaves Recall@5 unchanged and raises mean Recall@100 by 5.9 points. Removing the root costs 3.9 and 6.8 points on MuSiQue and FRAMES.

Options at a glance

  • levels=[1, 2] and levels=[1, 2, 3] read the prefixes RDR(2, 3) and RDR(3, 3) from one RDR(4, 3) run. The tree is forward-only, so a prefix equals the shallower search.
  • restrict_to_selected=True is readout B; with backfill_root=True the list is completed with the root ranking, as in the single-hop tables.
  • view="recovery" reads an auxiliary view of the traversal; see Recovery fusion.
Advanced: other per-state normalizations (normalization=)

rdr.GlobalReadout

"global"guide[source]
classrdr.GlobalReadout(temperature=0.05, top_k=200, level_balanced=True, include_root=True, levels=None, normalization='softmax', restrict_to_selected=False, backfill_root=False, output_top_k=200, view='primary')

Level-balanced aggregation of sparse per-state score distributions (RDR's default readout).

Parameters

  • temperaturefloatdefault 0.05

    Softmax temperature tau over raw cosine scores (paper: 0.05).

  • top_kintdefault 200

    Candidates retained per state, |C_s| (paper: 200).

  • level_balancedbooldefault True

    Average states within each level, then average non-empty levels (paper). If False every state gets equal weight (flat CombSUM).

  • include_rootbooldefault True

    Set False for the "without root" ablation (levels >= 2 only).

Advanced parameters (6)
  • levelsIterable[int] | Nonedefault None

    Only aggregate these levels (prefix readouts such as RDR(3,3) of an RDR(4,3) run).

  • normalizationstrdefault 'softmax'

    Per-state score map: "softmax" (paper), "raw", "minmax", "minmax_full".

  • restrict_to_selectedbooldefault False

    Readout B: keep only documents the search selected (E), same scores.

  • backfill_rootbooldefault False

    After restrict_to_selected, append the root ranking (single-hop protocol).

  • output_top_kint | Nonedefault 200

    Final sparse cut of the aggregated scores (paper: 200; None keeps everything).

  • viewstrdefault 'primary'

    Which view of the traversal to read ("primary" or e.g. "recovery").
