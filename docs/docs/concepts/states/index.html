Concepts

States & prompts

A state is the text s = [ι; q; ctx(O_s)]: an instruction, the query and the documents observed on its path. The encoder maps it to one vector, z_s = f_θ(s), which scores the fixed index, ℓ_s(d) = cos(z_s, e_d) (Eq. 1). Documents are encoded once and never change during search.

The root state has no observations. Every child appends one retrieved document to its parent's path, so a state at level h has observed h − 1 documents. How the instruction, the query and the observations are laid out is the prompt configuration. The paper uses one layout for multi-hop and another for single-hop suites. Below are the exact strings the package renders:

MuSiQue, BrowseComp+, FanOutQA, FRAMES: continuation replaces the root instruction.

Presets

  • "multi-hop" (default): the root uses the shared multi-hop root instruction. Deeper states replace it with continuation. Observations are Document i: lines, each capped at 512 tokens.
  • "single-hop": the root uses the benchmark's instruction, passed per call or per query. Deeper states keep it and add the recovery instruction after the query. One observation appears as Retrieved Context: / Document 1:; several appear as Incorrect document i:.
  • "single-hop-continuation" and "bright-pro": the single-hop layout with continuation as the update.
  • The recovery view of a multi-hop tree re-renders a proposal's path. It marks the last document as Retrieved (incorrect): and uses the chain-recovery instruction (recovery fusion).
python
from rdr import PromptConfig, RecursiveRetriever

retriever = RecursiveRetriever("RDR-8B", prompts="single-hop")        # a preset by name
prompts = PromptConfig.preset("multi-hop", observation_max_tokens=1024)     # a preset with overrides
retriever = RecursiveRetriever("RDR-8B", prompts=prompts)

Roles

Every state has a role that selects its instruction: root, the primary roles continuation and recovery, recovery_view (the auxiliary view), feedback (joint pseudo-relevance feedback) and assembly (set-conditioned selection). Search strategies set the primary role from the prompt configuration.

python
from rdr import PromptConfig, StateRenderer

renderer = StateRenderer(PromptConfig.preset("multi-hop"))
print(renderer.render("Which river flows through …?", ["Book X — written by author Y"], "continuation"))
# Instruct: Given the question and the documents already retrieved, retrieve the next document needed to continue answering it.
# Query:Which river flows through …?
# Document 1: Book X — written by author Y

A custom configuration

python
from rdr import ContextLayout, PromptConfig

prompts = PromptConfig(
    root="Given a question, retrieve passages that answer it",
    instructions={"continuation": "Given the question and the passages so far, retrieve the next one."},
    primary_role="continuation",
    wrap="keep",                                          # keep the root instruction, add the update line
    head="Instruct: {instruction}\nQuery: {query}",
    layouts={1: ContextLayout(header="Retrieved Context:")},   # one observed document
    default_layout=ContextLayout(item="Document {i}: {text}"),  # two or more
    observation_max_tokens=512,
)
The presets are the formats of the paper's evaluation runs. Other layouts and wordings run, but they are not what the paper measured. All fields are listed in the PromptConfig reference.
