Concepts

Search × readout

Two choices define a recursive retriever. The search decides which states the encoder sees, and the readout decides how their scores become one ranking. In rdr both are arguments of one call. Pseudo-relevance feedback, refinement chains, beam retrieval and document-as-query expansion are combinations of the two, and RDR is the learned tree read out globally (Figure 2 of the paper).
from rdr import *   # the classes below

families = {
    "as in ANCE-PRF": dict(
        search=JointFeedback(m=3),
        readout=StateReadout(level=2)),
    "as in DC-PRF": dict(
        search=ChainSearch(depth=4),
        readout=RootInterpolation(lam=0.8)),
    "as in BeamDR": dict(
        search=BeamSearch(width=5),
        readout=ProbabilityChain()),
    "as in COR": dict(
        search=DocAsQuerySearch(depth=4, branching=3),
        readout=PostOrderRRF()),
    "RDR": dict(
        search=TreeSearch(depth=4, branching=3),
        readout=GlobalReadout()),
}
for name, kw in families.items():
    hits = retriever.search(queries, index, **kw)
