Concepts

Instructions

Every state starts with an instruction. The root uses the benchmark's retrieval instruction; every context-bearing level uses one update instruction, continuation or recovery.

Continuation asks for evidence that is still missing given the observed documents. It drives the multi-hop trees and BRIGHT-Pro. Recovery treats the observed document as a distractor or partial observation and asks again for the document that satisfies the need. It drives the single-hop trees. Because the instruction is part of the state, the same observations encoded under the two roles give two views, which the optional recovery fusion combines.

python
from rdr import instructions

instructions.get("continuation")               # evidence completion (multi-hop, BRIGHT-Pro)
instructions.get("recovery")                   # relevance refinement (single-hop)
instructions.get("recovery_multihop")          # the optional recovery view of a multi-hop tree
instructions.root_for("bright", "biology")     # a benchmark's root instruction
instructions.root_for("coir", "cosqa")

Update instructions (levels ≥ 2)

keyinstruction
continuation"Given the question and the documents already retrieved, retrieve the next document needed to continue answering it."
recovery"The previously retrieved document is a distractor or partial observation. Given the query and this document, retrieve the document that fully satisfies the information need."
recovery_multihop"The previously retrieved document is a distractor. Given the question and this incorrect document, retrieve the correct document that continues the chain."

Custom instructions

Override any role in a preset, or pass a root instruction per call (a string for all queries, or one per query). The encoder was trained with the instructions above; other wordings work but are not what the paper measured.

python
from rdr import PromptConfig, RecursiveRetriever

prompts = PromptConfig.preset(
    "single-hop",
    instructions={"recovery": "Given the query and this near-miss document, retrieve the document that answers it."},
)
retriever = RecursiveRetriever("RDR-8B", prompts=prompts)
retriever.search(queries, index, instruction="Given a question, retrieve passages that answer it")
