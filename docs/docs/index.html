Recursive Dense Retrieval

One instruction-conditioned encoder maps a retrieval goal and the documents observed so far to the next query vector. Repeated encoding and index lookups build a retrieval tree, and the global readout scores every retained candidate with all of its states. The instruction is part of the state, so the same encoder refines single-hop queries (recovery) and follows multi-hop evidence chains (continuation).
from rdr import RecursiveRetriever

# TreeSearch(4, 3) + GlobalReadout()
retriever = RecursiveRetriever("RDR-8B")

# documents are encoded once
index = retriever.build_index(corpus)

# [{"corpus_id", "score", "index"}, ...] per query
hits = retriever.search(queries, index, top_k=10)

One operator, every recursive retriever

A recursive retriever makes two choices: which states form, and how their scores become a ranking. Pseudo-relevance feedback, refinement chains, beam retrieval and document-as-query expansion are combinations of these two choices, and rdr runs all of them with one encoder and one index:
