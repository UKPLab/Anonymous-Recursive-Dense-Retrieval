Running at scale

Evaluation

The metrics and benchmark loaders of the paper, so that a run of the package is scored the way the paper scores it.

Metrics

python
from rdr.evaluation import recall_at_k, ndcg_at_k, alpha_ndcg_at_k, macro

ranked = [hit["corpus_id"] for hit in hits]
recall_at_k(ranked, gold=[{"p1"}, {"p7", "p8"}], k=5)     # 2 gold groups; any member credits a group
ndcg_at_k(ranked, qrels={"d3": 1, "d9": 2}, k=10)        # binary gains for every rel > 0 (paper)
ndcg_at_k(ranked, qrels={"d3": 1, "d9": 2}, k=10, graded=True)
alpha_ndcg_at_k(ranked, aspects={"d3": ["a1"], "d9": ["a1", "a2"]}, k=10, alpha=0.5)
  • recall_at_k counts gold groups: a group is found when any of its members is in the top-k. MuSiQue and BrowseComp+ have one passage per group; FanOutQA and FRAMES group all passages of a source page.
  • ndcg_at_k uses binary gains for every rel > 0, as the paper's single-hop evaluation does; graded=True gives the pytrec_eval-style graded variant.
  • alpha_ndcg_at_k rewards covering new aspects (BRIGHT-Pro); the ideal ranking is the greedy approximation.
  • macro averages per-group means: tasks for NanoBEIR and BRIGHT, the 35 query groups for ToolRet, the ten datasets for CoIR.

Benchmarks

rdr.evaluation.benchmarks (extra eval) loads the single-hop suites from the Hugging Face Hub with the paper's repositories, splits, revisions and instruction strings, and reads the multi-hop suites from prepared files (Reproducing the paperdescribes them). Every loader returns a list of Tasks with corpus, queries, per-query root instructions, qrels, excluded ids and gold groups.

python
from rdr import RecursiveRetriever
from rdr.evaluation import benchmarks, ndcg_at_k, macro

retriever = RecursiveRetriever("RDR-8B", prompts="single-hop", document_max_length=8192)
per_task = {}
for task in benchmarks.load_nanobeir():                               # 13 tasks from the Hub
    index = retriever.build_index(task.corpus_texts, ids=task.corpus_ids, cache_dir=f"cache/{task.cache_key}")
    exclude = [index.positions(task.excluded_ids.get(q, ())) for q in task.query_ids]
    hits = retriever.search(task.query_texts, index, top_k=10,
                            instruction=task.query_instructions, exclude=exclude)
    per_task[task.name] = [ndcg_at_k([h["corpus_id"] for h in hs], task.qrels[q], 10)
                           for q, hs in zip(task.query_ids, hits)]
print(100 * macro(per_task))                                          # task macro, as in the paper
The paper encodes the single-hop corpora with up to 8192 tokens per document and the multi-hop passages with 512 (document_max_length). Query states use up to 4096 tokens in both.
