Search strategies

Joint feedback

Pseudo-relevance feedback as in ANCE-PRF: the root's top-m documents are rendered together into one second state, with the benchmark's instruction, and encoded into one query vector. Read out alone, that vector replaces the root ranking: one joint vector, one ranking.

Paper (Table 3a), joint feedback m = 3 vs the root: multi-hop mean Recall@5 38.15 vs 42.70; single-hop mean nDCG@10 52.71 vs 56.78.

Table 3a. Per suite (Tables 24, 30): joint feedback helps on BrowseComp+ and FanOutQA and falls below the root on MuSiQue, FRAMES and TopiOCQA.

Here several observations share one query vector, and the root's own ranking is not part of the output. RDR encodes every observation as its own state and keeps the root in the readout.

classrdr.JointFeedback(m=3)

Pseudo-relevance feedback as in ANCE-PRF: the query and the root's top-m documents are encoded jointly into one second query vector, read out alone (StateReadout(level=2)).

Parameters

  • mintdefault 3

    Feedback documents, the root's top-m, observed together by the second state (paper: 3).

"state"guide[source]
classrdr.StateReadout(level=None)

Ranking of the state at level (default: the deepest) — e.g. joint feedback, or the terminal state of a chain. With several states at that level the one with the best path score is used.

Parameters

  • levelint | Nonedefault None

    Level whose state is read (1 = root; None = the deepest encoded level).
