Search strategies

Document-as-query expansion

The tree of RDR, with the same geometry, eligibility and deduplication, but without learned updates. Each child searches with the selected document's own index vector, as when retrieved papers are promoted to queries (COR). Only the root is encoded. This separates what the learned state update contributes from what tree expansion alone contributes.

A document's own vector retrieves the document itself first, at cosine 1: each child's list is that document's neighbourhood in the index, not a state anchored in the query.

This is a COR-style expansion and aggregation, not a full reproduction of COR: its LLM-generated aspect queries are not part of the package.

classrdr.DocAsQuerySearch(depth=4, branching=3, root_branching=None, dedup='level', beam=None, path_score='raw')

Document-as-query expansion (COR-style, without COR's LLM aspect queries): same geometry, eligibility and deduplication as TreeSearch, but each child searches with the selected document's own index vector instead of an encoded state (Table 32).

Read it out with PostOrderRRF for COR's own aggregation, or with the default global readout.

Parameters

  • depthintdefault 4

    H, levels including the root (the root is still an encoded query).

  • branchingintdefault 3

    b, documents each state promotes to queries.

Advanced parameters (4)
  • root_branchingint | Nonedefault None

    Selections of the root (defaults to branching).

  • dedupstrdefault 'level'

    Selection rule, as in TreeSearch.

  • beamint | Nonedefault None

    Optional beam width, as in TreeSearch.

  • path_scorestrdefault 'raw'

    "raw" or "minmax" path scores, as in TreeSearch.
